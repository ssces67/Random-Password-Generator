# Random Password Generator

## Автор
Буханцов Богдан

## Описание
Графический генератор случайных паролей с настройками длины и типа символов. Генерируется пароль по выбранным параметрам, и все созданные пароли автоматически сохраняются в историю, которая хранится в файле `history.json`.

## Использование
1. Запустите программу `password_generator.py`.
2. Настройте ползунок длины пароля (от 6 до 32 символов).
3. Выберите типы символов: цифры, буквы, спецсимволы.
4. Нажмите кнопку "Генерировать".
5. Сгенерированный пароль появится в таблице истории.
6. История будет сохраняться между запусками.

## Требования
- Установлен Python 3.x (стандартно содержит библиотеки tkinter, json, random).

## Примеры тестов
- Установите длину 12, выберите все типы символов и нажмите "Генерировать". Убедитесь, что пароль появляется в таблице.
- Попробуйте оставить все чекбоксы выключенными — должно показывать предупреждение.
- Попробуйте установить длину вне допустимого диапазона — должно показывать ошибку.
